## 🛠️ Repository Organization

- `/papers` : Contains the standalone PDF manuscripts for all 8 experimental runs.
- `/src` : Contains clean, modularized PyTorch source scripts for modules, routing gates, and controllers.

## 🔬 Open-Science Provenance
In dedication to complete research transparency, every project listed here contains its explicit large language model (LLM) co-reasoning transparency statements, code generation scaffolding logs, and live originating conversational verification paths directly inside the front matter of the manuscripts.
